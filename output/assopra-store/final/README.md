# Assopra Store — portfolio assets

Approved English copy and 23 individual PNG assets for local review.

Open `index.html` through a local HTTP server. `media.json` records the image order, English descriptions and presentation type. `crop-manifest.json` records the source nodes and crop coordinates; source captures are preserved separately in the project workspace.

Device PNGs have transparent backgrounds and use the existing portfolio MacBook and iPhone frames. Screens retain their proportions. All nine MacBook crops match the screen area at 1.6:1 and fill it completely. Review titles and captions are not embedded in the images.

Components are separate files. Apply masonry, 16px gaps, 16px corner radii and a 1px pure-black border at 8% opacity in the presentation layer, without drop shadows or grey external backgrounds. Preserve internal design colours.

The three campaign images are excerpts from the supplied Figma home page. The designer confirmed authorship using AI; no new campaign imagery was generated while preparing this package.

This package has not been published to the portfolio.
