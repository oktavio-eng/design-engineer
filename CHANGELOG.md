# Changelog

Notable changes to this site, in the order they landed on `main`. Newest first. This is the technical log — for the narrated version, see `/changelog` on the site itself. See `AGENTS.md` for the deeper "why" behind several of these; a few entries below only summarize it.

## 2026-08-26

- Add interaction sound (`sound.mjs`, vendoring [cuelume](https://cuelume-site.pages.dev/) — MIT, Daniel Belyi — into `vendor/cuelume/`; the site has no bundler, so a bare `import "cuelume"` specifier wouldn't resolve in the browser even with the package listed in `package.json`, which only documents the source version). Synthesized live via Web Audio, zero audio files, zero network. Three roles, reused rather than invented per element: `tick` on hover for every "row that lifts like a card" — the navbar links, `#mailTrigger`, and the whole family `cursor.mjs`'s `MERGE` selector already treats as one group (`main > section .row`, `.row-btn`, `.doc-item`, `.cmd__item`); `bloom` on the click that opens a panel or detail view; `droplet` on every `.panel-close` "×" (`#panelClose`, `#cpanelClose`, `#aboutClose`, `#avatarClose`, the portfolio lightbox, the ⌘K/prompts detail modal — `#cmdModalBack` stays silent on purpose, it isn't a close). `#themeTrigger` uses the library's own default toggle click; `prompts.mjs` calls `play("success"|"error")` imperatively right after `navigator.clipboard.writeText` in `attachPromptCopy()`. All declarative through `data-cuelume-*` attributes in the markup/templates — no new event-listener code beyond `sound.mjs`'s own two-line `bind()`.
- Capitalize the primary navbar labels on all four pages: `home/wiki/changelog/prompts` → `Home/Wiki/Changelog/Prompts`.
- The home page's link to `/wiki` now reads "Read the wiki" instead of "Read the plan".

## 2026-08-16

- iPadOS-style pointer on every page (`cursor.mjs`, new `--cursor-*` tokens, an "iPadOS pointer" block at the end of `main.css`): the OS arrow gives way to the pointer iPadOS draws for a mouse (and macOS 27 adopted) — a 20px translucent dot following 1:1, an I-beam over text locked to the line box (real glyph hit test via `caretPositionFromPoint`), and a rounded highlight that snaps around links and buttons with a touch of parallax, springing back to a dot on the way out; fades after 2s idle, shrinks on press, hides off-window. Rows, doc rows and ⌘K items that already paint their own hover *merge* (the pointer takes their exact shape and fades into them — one highlight, never two; the measured jakub.kr row fill is untouched); image buttons (avatar, gallery) get a ring instead of a dimming fill; text-only links get the pill around the text's box, not the padded hit box. Native cursor hidden without `!important` (id-weight `:not(#\#)` chain) so `[data-cursor="native"]` on the sidebar resize handle keeps `col-resize`. Only mounts on fine-pointer/hover devices, never under `prefers-reduced-motion`, and only turns on at the first real mouse move — keyboard and touch never see it. Storybook story with the six resting states painted by the real `paintCursor()`; `tests/ui/cursor.test.mjs` drives the live behaviour on the real pages.

- Make the ⌘K command palette work on every page and index the prompts. The palette moved out of `script.js` (which only `index.html` loads, and can't be loaded elsewhere — see the notes in `changelog.html`/`prompts.html`) into a shared ES module, `cmd.mjs`, that builds its own wash/list/detail markup on load, so `index.html` no longer carries it.
