What I do

I design interfaces and, increasingly, build them: visual design first, moving toward design engineering — the same eye for type, color, spacing and motion, now with the code to carry a decision all the way to the screen. I work remotely from Brazil, mostly with product teams and small studios that care about how software feels, not only that it works.

The plan for that transition is public, and this site is its first proof: everything here — the palette, the ⌘K search, the tests behind it — is written down as it ships. Read the plan or the changelog.
